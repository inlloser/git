| 操作                             | 命令                                                |
| -------------------------------- | --------------------------------------------------- |
| 把修改保存到暂存区               | git add .                                           |
| 把暂存区提交                     | git commit -m "备注"(每次提交必须备注)(-m是message) |
| 随时回退最近的版本               | git restore .                                       |
| 查看历史提交记录                 | git log  或者  git log --oneline                    |
|                                  |                                                     |
| 查看当前有哪些分支               | git branch                                          |
| 创建并切换名称                   | git switch -c "分支名"                              |
| 查看远程                         | git remote -v                                       |
| 从远程拉下来                     | git pull                                            |
| 提交到远程                       | git push                                            |
| 把本地main分支的提交传到远程仓库 | git push -u origin main                             |
|                                  |                                                     |
| 融合指定分支到当前分支           | git merge 分支名                                    |
| 查看当前分支状态                 | git status                                          |
