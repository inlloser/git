| 操作               | 命令                                                |
| ------------------ | --------------------------------------------------- |
| 把修改保存到暂存区 | git add .                                           |
| 把暂存区提交       | git commit -m "备注"(每次提交必须备注)(-m是message) |
| 随时回退最近的版本 | git restore .                                       |
| 查看历史提交记录   | git log                                             |
|                    |                                                     |
| 查看当前有哪些分支 | git branch                                          |
| 创建并切换名称     | git switch -c "分支名称"                            |
| 查看远程           | git remote -v                                       |
| 提交到远程         | git pull                                            |
| 从远程拉下来       | git push                                            |
